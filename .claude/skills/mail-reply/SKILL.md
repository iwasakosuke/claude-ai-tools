# メール返信ドラフト作成

## 目的
返信文を考える時間と「文面のトーンの迷い」をなくす。人間は読んで送信ボタンを押すだけ。

## 手順
1. 対象スレッドをGmail MCPで取得し、経緯と相手の要求を把握する
2. `templates/メール返信パターン集.md` を読み、該当パターンと文体サンプルに合わせる
3. 返信ドラフトを作成する。判断が必要な箇所(可否・日程・金額など)は `【要判断: ○○】` とプレースホルダで明示し、勝手に確定しない
4. `checklists/qa-文章.md` でセルフチェックする
5. ドラフト本文をチャットに提示し、**承認を得てから** Gmailの下書き(create_draft)に保存する

## 出力形式
```
## ✉️ 返信ドラフト
宛先: / 件名:
---
(本文)
---
✅ セルフQA: 宛名・敬称OK / 結論が冒頭 / 期日明記 / 添付言及の整合
★ 要判断: (人間が決める箇所の一覧。なければ「なし」)
```

## 品質基準
- 結論を最初の2文以内に書く
- 相手の質問には番号を付けて全部に答える(答え漏れがQAの最重要項目)
- 長さは相手のメールと同等以下を目安にする

## 安全ルール
- **送信は絶対にしない**。下書き保存まで。下書き保存も本文提示→承認後
- 金額・契約条件・日程確約は `【要判断】` にして人間に委ねる
