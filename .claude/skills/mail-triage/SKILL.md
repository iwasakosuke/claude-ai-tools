# メールトリアージ

## 目的
受信メールを読む・仕分ける時間をゼロに近づける。人間は一覧を見て対応を決めるだけ。

## 手順
1. Gmail MCPで直近の未読・未対応スレッドを検索する(既定: 過去48時間、依頼があれば期間変更)
2. 各スレッドを以下に分類する:
   - **A: 今日返信が必要**(相手が返事を待っている・期限がある)
   - **B: 今週中に対応**(依頼・確認事項だが急ぎでない)
   - **C: 読むだけでよい**(共有・通知・メルマガ)
   - **D: 対応不要**(スパム・自動通知)
3. A/Bの各メールについて「一言サマリ+推奨アクション+返信の要点案」を付ける
4. 結果を下の出力形式で提示する

## 出力形式
```
## 📬 メールトリアージ結果(YYYY-MM-DD HH:MM)
### 🔴 A: 今日返信(N件)
1. [差出人] 件名 — 要旨1行
   → 推奨: 返信の要点(2行以内)
### 🟡 B: 今週対応(N件)
...
### ⚪ C: 読むだけ(N件) — 件名のみ列挙
### 対応不要: N件(内訳1行)
```

## 続けてできること
- 「1番の返信ドラフト作って」→ `mail-reply` Skillに引き継ぐ

## 安全ルール
- メールの送信・アーカイブ・削除・ラベル変更は**行わない**(依頼された場合もラベル付与まで。削除は不可)
- メール本文の内容を外部サービスに送らない
