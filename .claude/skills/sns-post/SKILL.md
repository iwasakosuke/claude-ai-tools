# SNS投稿・デザイン指示作成

## 目的
投稿文のトーンのブレをなくし、「文章+画像指示」をワンセットで量産できるようにする。

## 手順
1. 投稿の目的(告知/集客/ナレッジ共有/ブランディング)と媒体を確認する。不明なら仮説を置いて明記する
2. `templates/SNS投稿テンプレート.md` のトーン定義・NG表現に従って投稿文を作る
3. 媒体別に最適化する(文字数・ハッシュタグ・改行リズム)。1案ではなく**3案**(堅め/標準/カジュアル)出す
4. 画像が必要な場合は「Canva用デザイン指示」(サイズ・レイアウト・文言・色味)を添える。依頼があればCanva MCPでドラフト生成する(**新規デザインとして**。既存デザインの上書き禁止)
5. `checklists/qa-デザイン.md` でセルフチェックする

## 出力形式
```
## 📱 投稿案(媒体: X / 目的: 告知)
### 案A(標準)
(本文)
#ハッシュタグ
### 案B(堅め)/ 案C(カジュアル)
...
## 🎨 デザイン指示(必要な場合)
サイズ: / メイン文言: / レイアウト: / トーン:
✅ セルフQA結果
```

## 安全ルール
- **投稿・予約投稿は絶対にしない**。文面と画像案の作成まで
- 他社・他人への言及、実績数値、キャンペーン条件は `【要確認】` を付ける
- 画像の生成・エクスポートで課金が発生する場合は事前確認
