# 週報・定型レポート作成

## 目的
「今週何やったっけ」を思い出す時間と、レポートの体裁を整える時間をゼロにする。

## 手順
1. 材料を集める(使えるものだけでよい):
   - このリポジトリ・関連リポジトリの今週のコミットログ(`git log --since`)
   - `work/` 内の今週作成したファイル(議事録・提案書など)
   - 依頼者が貼ったメモ・箇条書き
2. `templates/週報テンプレート.md` に沿って整形する
3. 実績は「やったこと」ではなく「出した結果」で書く(例:「提案書作成」→「ABC商事向け提案書v2を提出」)
4. 数値・固有名詞は材料にあるものだけ使う。推定した数値には `(概算)` を付ける
5. 「所感・来週の重点」はドラフトを書くが `★要確認` を付け、人間の言葉に差し替えてもらう

## 出力形式
`templates/週報テンプレート.md` に従う。

## 保存
- `YYYYMMDD_週報_v1.md`。提示→承認後に保存
- 毎週金曜に自動でドラフトを作る運用に移行できる(Phase 3: 定期実行トリガー)。設定は依頼があったときのみ

## 安全ルール
- 未確定の成果(受注見込み等)を確定のように書かない
- 提出・共有は人間が行う
