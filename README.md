# claude-ai-tools
Claude Codeで作るAI自動化ツール

**このリポジトリは「業務資産」です。** Claude Codeでこのリポジトリを開いて依頼するだけで、Skillが自動的に使われます。

## 🚀 使い方(3ステップ)

1. Claude Code(Web/CLI/アプリ)でこのリポジトリを開く
2. 普通に依頼する — 例:
   - 「メール整理して」→ 受信箱を仕分けて要対応一覧を作る
   - 「このメールの返信作って」→ あなたの文体で下書き作成(送信はしない)
   - 「このメモ議事録にして」→ 決定事項・ToDo付き議事録
   - 「週報作って」「〜について調べて」「〜の提案書作りたい」「SNS投稿作って」「〜を自動化するスクリプト作って」
3. 週1回「週次レビューして」→ 使った結果をSkill・テンプレに還元して資産を育てる

## 📁 構成

| 場所 | 中身 |
|---|---|
| `docs/` | 戦略(何をAI化するか)・運用ルール(命名/保存/安全)・効果ログ |
| `.claude/skills/` | 9つのSkill(mail-triage / mail-reply / minutes / weekly-report / research-brief / proposal-draft / sns-post / dev-script / asset-review) |
| `templates/` | 成果物の型(提案書・議事録・週報・リサーチ・メール・SNS) |
| `checklists/` | 提出前QAチェックリスト(文章・提案書・デザイン・コード) |
| `prompts/` | claude.ai等でも使える持ち出し用プロンプト集 |
| `work/` | ドラフト置き場 / `tools/` 自作スクリプト置き場 |

## 🔒 安全原則(全Skill共通)

メール送信・SNS投稿・外部送信・課金・既存ファイルの上書き/削除は、AIは**絶対に勝手に実行しない**。詳細: `docs/02_運用ルール.md`

## 🌱 資産を育てる一番のコツ

- `templates/メール返信パターン集.md` に自分の実際のメールを3〜5通貼る(文体再現の精度が激変)
- AIの出力を手で直したら、その直しをテンプレ/Skillに反映する(週次レビューで自動提案されます)
