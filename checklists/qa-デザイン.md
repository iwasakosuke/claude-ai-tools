# QAチェックリスト: デザイン・画像・SNS投稿

## 文言
- [ ] 誤字がない(画像内の文字は特に見落としやすい)
- [ ] 数値・日付・価格・期間が正しい(キャンペーン系は特に)
- [ ] NG表現(誇大・断定・他者批判)がテンプレ定義に照らしてない
- [ ] ハッシュタグ・メンションのスペルが正しい

## ビジュアル
- [ ] 媒体の推奨サイズと一致している
- [ ] メイン文言がサムネイル/縮小表示でも読める
- [ ] ロゴ・ブランドカラーの使い方が定義どおり(定義があれば)

## ★人間判断
- [ ] ★ 実績・数値は公開してよい確定情報か
- [ ] ★ 権利物(他者の写真・ロゴ・キャラクター)が写り込んでいないか
- [ ] ★ 投稿タイミング・投稿アカウントは正しいか(投稿は必ず人間が行う)
