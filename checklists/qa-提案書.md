# QAチェックリスト: 提案書・プレゼン資料

## ストーリー
- [ ] スライドタイトルだけを順に読んで話が通じる
- [ ] 課題→解決→効果→費用→次のアクション の順になっている
- [ ] 1スライド1メッセージになっている(2つ以上言いたいスライドは分割済み)
- [ ] 相手の課題が相手の言葉(ヒアリング内容)で書かれている

## 中身
- [ ] 効果に数字または事例がある
- [ ] 「次のアクション」が小さく具体的(相手が即答できる粒度)
- [ ] 図解すべきページに図解案 or デザイン指示がある
- [ ] 誤字・表記ゆれ・スライド番号を確認した

## ★人間判断
- [ ] ★ 金額・納期・スコープの記載は確定してよい内容か(【要判断】が残っていないか)
- [ ] ★ 事例の固有名詞は公開許可があるか
- [ ] ★ 決裁者がこれを見て「で、いくらで何をしてくれるの?」に即答できるか
