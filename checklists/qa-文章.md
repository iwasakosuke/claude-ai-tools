# QAチェックリスト: 文章系(メール・議事録・報告書)

AIは提出前に自分でチェックし、結果を成果物に添える。★は人間だけが判断できる項目。

## 内容
- [ ] 結論・決定事項が冒頭にある
- [ ] 相手の質問・依頼のすべてに答えている(番号を振って照合した)
- [ ] 日付・数値・固有名詞が材料と一致している(推定には「(推定)」がある)
- [ ] 期日・担当が書いてある(不明なものは【未定】と明示されている)
- [ ] 材料にないことを書いていない(創作なし)

## 表現
- [ ] 宛名・敬称・社名の表記が正しい
- [ ] 一文が長すぎない(目安60字)。二重否定がない
- [ ] トーンがパターン集/テンプレの定義と一致している

## ★人間判断(AIはチェック不可・必ず目視)
- [ ] ★ 金額・契約条件・確約表現は意図どおりか
- [ ] ★ この内容を相手に見せて問題ないか(機密・感情面)
- [ ] ★ 送信先・共有先は正しいか
