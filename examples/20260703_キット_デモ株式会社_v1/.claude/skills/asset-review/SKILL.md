# 資産レビュー(週次)

## 目的
「作って終わり」を防ぐ。使った結果をSkill・テンプレに還元し、資産を毎週少しずつ賢くする。

## 手順
1. 今週の状況を聞く(3つだけ):
   - よく使ったSkillはどれか / 出力を手で直した箇所はどこか / 面倒だった作業で型がないものは何か
2. リポジトリの状態を確認する:
   - `git log --since='1 week ago'` で今週の変更を見る
   - `work/` の今週のファイルから、直された痕跡(v2以降のファイル)を探す
3. 改善提案を出す(最大3件。多すぎる改善は実行されない):
   - Skill/テンプレの修正案(diff形式で具体的に)
   - 新しくSkill化すべき作業(docs/01 の判断基準: 週1以上×15分以上×低リスク)
   - 捨てるべきSkill(2週間使われていないもの)
4. 承認された改善を適用し、`improve: <対象> <理由>` でコミットする
5. 効果記録を `docs/03_効果ログ.md` に1行追記する(日付 / 変更 / 期待効果)

## 出力形式
```
## 🔄 週次資産レビュー(YYYY-MM-DD)
### 今週の利用状況(1〜2行)
### 改善提案(最大3件)
1. [skill名] 変更内容 — 理由
### 新規Skill候補 / 廃止候補
### 判断してほしいこと(★)
```

## 安全ルール
- Skillの削除は提案のみ。実削除は承認後
- 効果ログは追記のみ。過去の記録を書き換えない
