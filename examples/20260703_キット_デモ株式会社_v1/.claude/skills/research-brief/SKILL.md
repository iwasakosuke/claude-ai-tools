# リサーチブリーフ作成

## 目的
「調べたが結局どうすればいいか分からない」を防ぐ。調査は必ず**推奨アクションつきの1枚ブリーフ**で終える。

## 手順
1. 最初に「この調査で答えるべき問い」を1文で定義し、依頼とズレていないか確認する(ズレの手戻りが最大のコスト)
2. Web検索・提供資料・リポジトリ内の過去ブリーフ(`work/` 配下)を調べる
3. 情報は**出典つき**で集める。出典のない情報は「未確認」と明示する
4. `templates/リサーチブリーフ.md` に整形する。構成は結論ファースト:
   - 問い → 結論(3行以内)→ 推奨アクション → 根拠 → 比較表 → 出典 → 調べていないこと
5. 「調べていないこと・わからなかったこと」を必ず書く(判断者が過信しないため)

## 品質基準
- 結論は「〜と思われる」で逃げない。確度を「高/中/低」で明示して言い切る
- 比較は必ず表にする(選択肢×評価軸)
- 出典は一次情報を優先。個人ブログのみが根拠のときはその旨明記

## 保存
- `YYYYMMDD_リサーチ_テーマ_v1.md`。承認後に保存

## 安全ルール
- 有料サービスへの登録・課金が必要な調査は、実行前に必ず確認する
- 社内情報・顧客情報を検索クエリに含めない
