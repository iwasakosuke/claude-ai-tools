# QAチェックリスト: コード・自動化スクリプト

## 動作
- [ ] 実データのコピー or ダミーデータで実行し、結果を確認した(結果を納品時に添付)
- [ ] 入力が空・不正・巨大なときに壊れず、分かるエラーメッセージを出す
- [ ] 破壊的操作(削除・上書き・送信)には --dry-run があり、dry-run結果を先に確認した

## 安全
- [ ] 認証情報がコード・ログ・コミットに含まれていない(環境変数で受け取る)
- [ ] 外部送信・課金APIの呼び出しがある場合、その旨が README と納品報告に明記されている
- [ ] 対象外のファイル・フォルダに触らない(対象はパス指定で限定されている)

## 資産化
- [ ] README がある(1行説明 / コピペで動く使い方 / 入出力 / 環境変数 / 注意)
- [ ] ブランチで開発し、mainに直接pushしていない
- [ ] 3ヶ月後の自分が読んで直せる(マジックナンバーに説明がある)

## ★人間判断
- [ ] ★ 本番データ・本番環境で実行してよいか
- [ ] ★ 定期実行にするか、手動実行のままにするか
