# SNS投稿テンプレート(トーン定義・媒体別ルール)

`sns-post` Skillが参照する。実際の過去投稿を貼るとトーン再現の精度が上がります。

## トーン定義 【仮説・要調整】
- 一人称: 「私」/ 敬体ベース、体言止めは見出しのみ
- 専門性を感じさせつつ、上から目線にしない
- 絵文字は1投稿2個まで。感嘆符の連続(!!)は使わない

## NG表現
- 誇大表現(「絶対」「100%」「日本一」等の根拠なき断定)
- 他社・他人の批判、比較での貶め
- 未確定の実績・数値(→ 投稿前に【要確認】を付ける)

## 媒体別ルール
| 媒体 | 文字数目安 | 型 |
|---|---|---|
| X | 140字以内(超えるならスレッド化を提案) | フック1行 → 本文 → 行動喚起 |
| Instagram | 冒頭2行で惹く(折りたたみ前提) | 画像が主役。本文は補足+ハッシュタグ5〜10 |
| LinkedIn/note等 | 制限なし | 結論→経験談→学び の順 |

## 投稿の基本構造
```
1行目: フック(数字・意外性・問いかけのどれか)
本文 : 1メッセージに絞る。改行を多めに
最後 : 行動喚起(詳細はリンク / コメントで教えてください 等)
```

## デザイン指示の型(画像つき投稿)
```
サイズ: (X: 1200x675 / Instagram: 1080x1080)
メイン文言: (画像内に入れる最重要の一言・13字以内目安)
レイアウト: (例: 中央に文言、下部にロゴ)
色味・トーン: (ブランドカラーがあればここに定義)
```
