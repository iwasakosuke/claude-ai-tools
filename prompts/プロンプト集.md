# プロンプト集(Claude Code以外でも使える持ち出し版)

claude.ai・スマホアプリなど、このリポジトリのSkillが使えない環境用。Skillの中身を単発プロンプトに圧縮したもの。`{}` を埋めて貼り付ける。

---

## 1. メール返信ドラフト
```
以下のメールへの返信ドラフトを作ってください。
条件: 結論を最初の2文以内に / 相手の質問すべてに番号付きで回答 / 敬体・標準的なビジネストーン / 金額や日程など私が決めるべき箇所は【要判断】と書いて空けておく / 送信はしない、文面だけ。
返信の方向性: {受ける・断る・催促する・日程調整 など}
--- 元メール ---
{貼り付け}
```

## 2. 議事録整形
```
以下のメモを議事録に整形してください。
形式: 冒頭に「決定事項」「ToDo表(やること/担当/期限)」を置き、その後に議題別の要点。
ルール: メモにないことを書かない / 担当・期限が不明なものは【未定】と明示 / 曖昧な発言は「〜という趣旨」と書く。
会議名: {} 日時: {} 参加者: {}
--- メモ ---
{貼り付け}
```

## 3. リサーチブリーフ
```
「{調べたいこと}」について調べて、意思決定用の1枚ブリーフにまとめてください。
構成: 問い(1文)→ 結論(3行以内・確度を高/中/低で明示して言い切る)→ 推奨アクション → 比較表(選択肢×コスト・手間・リスク)→ 根拠(出典URL付き)→ 調べていないこと。
出典のない情報は「未確認」と明記してください。
```

## 4. 提案書の構成案
```
{相手}向けの提案書のスライド構成案を作ってください。まだ本文は書かないでください。
流れ: 表紙→現状の課題→放置リスク→解決の方向性→提案内容→効果→事例→費用→次のアクション。
各スライドはタイトル+1行メッセージのみ。1スライド1メッセージ。
前提情報: 相手の課題={} / 提供するもの={} / 決裁者={}
不明な部分は仮説を置いて【仮説】と明記してください。
```

## 5. SNS投稿 3案
```
{媒体}向けの投稿を3案(標準/堅め/カジュアル)作ってください。
目的: {告知・集客・ナレッジ共有}
ルール: 1行目は数字・意外性・問いかけのどれかでフック / 誇大表現なし / 絵文字2個まで / {媒体の文字数制限}以内 / 未確定の実績数値には【要確認】を付ける。
投稿したい内容: {}
```

## 6. 万能: 作業の型化
```
私は「{くり返している作業}」を毎回ゼロから考えていて時間がかかります。
この作業を (1)手順書(SOP) (2)成果物テンプレート (3)提出前チェックリスト の3点セットに型化してください。
判断が必要な箇所と機械的にできる箇所を分け、機械的な部分はAIに任せられる形にしてください。
```
